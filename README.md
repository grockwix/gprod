# Описание

Проект является "сайтом-портфолио". Сайт разделен на 4 главные секции:

1. Главный заголовок сайта с изображением и кнопкой для перехода к 4 секции (форма обратной связи).
2. Бесконечная горизонтальная лента с логотипами компаний, которые сотрудничают (логотипы взяты в качестве примера).
3. Показ 3-х видео работ, которые по нажатию направляют на сайт (Vimeo) для полного просмотра.
4. Форма для обратной связи.

Главной секцией является 4 (Обратная связь). Форма обратной связи включает в себя:

- Валидация формы (проверка осуществляется при помощи регулярных выражений)
- Кнопки для очистки полей
- Динамическое изменение размера поля "Сообщение".

Также для отправки тестовых сообщений на почту с формы разработан простой SMTP сервер (папка **server**).

# Запуск

Проект собран на **Vite 7.0.5**.
Запуск клиента (папка **client**) командой:

```
npm run dev
```

Запуск сервера (папка **server**) командой:

```
npm run smtp
```

# Фреймворки

Клиентское приложение включает следующие зависимости:

- React + TypeScript
- React-Router
- React-intersection-observer (библиотека для динамической загрузки видимых областей)
- Redux Toolkit
- Axios (для отправки запросов на сервер)
- Sass (как dev зависимость)

Серверное приложение включает следующие зависимости:

- Express
- Nodemailer
- Cors

Также форматирование кода осуществляется при помощи Prettier.
